# Dennis Portfolio (React + Vite)

個人作品集網站，使用 React + Vite + Tailwind CSS。

## 執行指令

### 1) 安裝套件

```bash
npm install
```

### 2) 本地開發

```bash
npm run dev
```

- 預設會啟動在 `http://localhost:5173`

### 3) 正式建置

```bash
npm run build
```

- 輸出目錄：`dist/`

### 4) 本地預覽 build 結果

```bash
npm run preview
```

## Tech Stack

- React
- Vite
- Tailwind CSS
- Framer Motion
